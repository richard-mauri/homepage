# Homepage current work

**Date:** 2026-11-02. **Status:** Draft backend integration for Issue #2; not merged or deployed.

- Authoritative merged baseline: `main`; scoped working branch: `feat/central-suite-storage`, draft PR #3.
- The previous `feat/versioned-build-workflow` candidate is separate and not silently merged.
- Implemented: `internal/suitestore` validates NewsGo-style hashed tokens (ordinary and admin users), stores per-user/per-app revisioned JSON, performs atomic writes, checks write conflicts, and has auth/isolation tests.
- Added `configureSuiteStorage` to Homepage's Go server. **Default disabled**; with operator-set `SUITE_DATA_DIR`, GET/PUT `/api/storage/{newsgo|mauristocks}` endpoints are registered and require bearer tokens. No token registry or NewsGo data is migrated automatically. Without a populated `SUITE_DATA_DIR/auth/approved-tokens.json`, authentication fails closed. Use a private Mac directory outside source control.
- Added opt-in session endpoints at `/api/session`: same-origin POST using existing bearer token establishes a random 12-hour Secure, HttpOnly, SameSite=Lax cookie scoped to themauris.org; GET reports current session; DELETE logs out. Sessions are in process memory and do not persist across restart. **Storage API now accepts validated browser sessions or bearer tokens.** Session requests revalidate the token digest and role against the approved-token registry on each use, so revocation takes effect without waiting for expiration. Cookie-authenticated writes require a same-origin Origin header (no cross-origin CORS support yet). No browser UI and no cross-subdomain app integration exist yet. Do not enable this on the live tunnel.
- Added `.github/workflows/ci.yml` for Go tests and macOS cross-builds. Previous CI passed on prior heads; check CI on the exact latest PR head. No visual diffs (no HTML/CSS/JS changes).
- Added opt-in `/api/admin/users` backend API for admin-only user listing (no digests), token issuance/rotation, role changes and revocation. Preserves user settings on rotation/revocation; protects against removal of the last administrator. Newly issued token is returned once.
