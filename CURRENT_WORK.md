# Homepage current work

**Date:** 2026-11-02. **Status:** Draft backend integration for Issue #2; not merged or deployed.

- Authoritative merged baseline: `main`; scoped working branch: `feat/central-suite-storage`, draft PR #3.
- The previous `feat/versioned-build-workflow` candidate is separate and not silently merged.
- Implemented: `internal/suitestore` validates NewsGo-style hashed tokens (ordinary and admin users), stores per-user/per-app revisioned JSON, performs atomic writes, checks write conflicts, and has auth/isolation tests.
- Added `configureSuiteStorage` to Homepage's Go server. **Default disabled**; with operator-set `SUITE_DATA_DIR`, GET/PUT `/api/storage/{newsgo|mauristocks}` endpoints are registered and require bearer tokens. No token registry or NewsGo data is migrated automatically. Without a populated `SUITE_DATA_DIR/auth/approved-tokens.json`, authentication fails closed. Use a private Mac directory outside source control.
- Added opt-in session endpoints at `/api/session`: same-origin POST using existing bearer token establishes a random 12-hour Secure, HttpOnly, SameSite=Lax cookie scoped to themauris.org; GET reports current session; DELETE logs out. Sessions are in process memory and do not persist across restart. **Storage API now accepts validated browser sessions or bearer tokens.** Session requests revalidate the token digest and role against the approved-token registry on each use, so revocation takes effect without waiting for expiration. Cookie-authenticated writes require a same-origin Origin header (no cross-origin CORS support yet). The separate admin UI exists; app client integration is still pending. Do not enable this on the live tunnel.
- Added `.github/workflows/ci.yml` for Go tests and macOS cross-builds. Previous CI passed on prior heads; check CI on the exact latest PR head. New standalone HTML administration UI requires visual/accessibility acceptance when enabled; main launcher layout unchanged.
- Added opt-in `/api/admin/users` backend API for admin-only user listing (no digests), token issuance/rotation, role changes and revocation. Preserves user settings on rotation/revocation; protects against removal of the last administrator. Newly issued token is returned once. The standalone administrator UI is implemented; the API remains disabled unless `SUITE_DATA_DIR` is set.\n- Added opt-in standalone `/suite-admin` page for token-based login, session status/logout, and administrator-only user listing/issuance/role changes/rotation/revocation. Existing Homepage launcher UI files remain unchanged; new page requires Safari accessibility/visual testing at integration acceptance. Token shown only on issuance/rotation; UI deliberately does not save raw tokens in localStorage.\n- Added a narrowly allowlisted credentialed storage CORS policy for `home.themauris.org`, `stocks.themauris.org`, and `newsgo.themauris.org`. Existing sessions permit `GET/PUT /api/storage/{app}` from these origins; untrusted origins and cookie writes lacking Origin are rejected. Added CORS and negative-origin tests. This does not automatically integrate app clients or permit cross-origin token-management operations.\n- Added optional sign-in panel to the main Homepage launcher. The browser-only experience remains the default. When suite storage is configured, the panel permits token login, identity display, logout, and admin navigation without saving token values in localStorage or modifying app settings. It is a login/session milestone only: NewsGo and MauriStocks still use their prior local behavior until individual client integration, and signing in alone does NOT synchronize them yet. The panel needs visual and Safari acceptance.\n- **Remaining:** cross-subdomain client integration and session policy review, security review, persistent root provisioning, backup/recovery and migration, initial credential registry migration, NewsGo and MauriStocks integration, final Mac/Safari/Cloudflare acceptance.
